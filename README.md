# Asia-Legal-Dossier

Interactive intelligence dashboard mapping 13 booming legal systems across Asia and the Middle East, built as a Palantir-style network dossier.

## Stack
- React + TypeScript + Vite
- TailwindCSS
- Custom canvas-based force-directed graph
- Lucide icons

## Data Coverage
Saudi Arabia, UAE (DIFC/ADGM), China, Hong Kong, Singapore, Vietnam, Indonesia, Philippines, Japan, South Korea, India, Malaysia, Thailand, Australia.

## Run locally
```bash
npm install
npm run dev
```

## Build
```bash
npm run build
```
